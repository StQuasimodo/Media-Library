# 局部动效顿挫修复记录

本轮针对完整动效中可复现的顿挫，保留现有布局、海报、字体与影院风格。数据库、媒体源、播放器内核和更新流程不在修改范围。

## 修复

- 影视库海报：链接本身保持静止，封面子层承担上移与放大，消除边缘悬停进出循环；移除整墙常驻will-change。
- 首页轨道：选中尺寸的布局盒固定，通过scale切换，避免宽高动画逐帧重排；1440、1024、1920窗口的选中尺寸保持原值。
- 顶部导航：目标宽度只写一次，使用Web Animations FLIP过渡；快速切页读取当前可见位置，合并重复ResizeObserver／字体通知。运行中切换减少动效会取消空间动画。
- 专题／想看：页面负责淡入，页题只负责位移，消除父子透明度叠乘；系列文件夹的translate补齐过渡。海报墙与文件夹互切使用独立170ms反馈，首次进页不叠加淡入。
- 详情滚动：ResizeObserver缓存主视觉高度；参数仅作用于背景、遮罩、标题；为当前模糊层单独提供合成提示，保留12px渐变模糊外观。
- 专题轨道：脚本滚动遵守应用与系统的减少动效设置。
- TV首页：替换API21/22连续调用smoothScrollTo可能跳位的路径，改为可从当前scrollX连续转向的220ms动画；离开页面取消，关闭系统动效直接定位。

## 实测

2026-11-14，在同一Linux无头Chromium、1440×900、相同23部受控收藏和图片下，对比修改前后生产构建。指标是本次样本，不能直接外推到Windows GPU或长虹电视。

| 场景 | 修改前 | 修改后 |
|---|---:|---:|
| 一次导航切换的LayoutCount增量 | 20 | 5 |
| 一次首页海报切换的LayoutCount增量 | 11 | 2 |
| 静止鼠标在海报下边缘的进入／离开次数 | 3／2 | 1／0 |
| 文件夹封面过渡中间状态 | 直接跳到-6px | 能采样到中间位置 |
| 约一秒详情滚动采样的渲染帧 | 21 | 49 |
| 同段详情滚动大于34ms的帧间隔数 | 15 | 1 |
| 滚动期间读取主视觉offsetHeight次数 | 20 | 0 |

导航宽度变化仍有一次正常布局，页面和异步图片也会产生布局；本轮没有宣称“零重排”或“稳定60fps”。详情合成会使用当前背景层的显存，没有创建磁盘模糊缓存。

验证结果：

- TypeScript与生产构建通过；243个Vitest业务测试通过。
- 31项浏览器渲染与交互检查通过，覆盖快速切页、动画中途减少动效、卡片稳定命中、三组窗口尺寸、详情渐变与标题移动、系统／应用内减少动效。
- Android应用APK、instrumentation APK与lintDebug构建通过；minSdk21、ARMv7/x86配置保持不变。
- 增强现有Windows desktop-smoke：轨道布局尺寸固定、导航布局宽度只在目的地变化、海报命中区域稳定。
- 增加5项原生MotionScenario检查：中间位置、连续转向不瞬移、最终位置、减少动效立即定位、离开后取消。测试APK已编译，本地尚未执行这些API22 instrumentation断言。
- 当前环境无Electron二进制与Android模拟器；本地没有新增Windows原生窗口、API22运行或长虹实机验收结论。
