# My Cinema TV 0.1.0-alpha.3

- 背景改用高清横版图库，优先无字、至少1280×720、接近16:9；不再拿本季首张单集剧照当背景。候选足够时按季稳定分配，同剧图库变体不冒充某季官方宣传图；不足时共用合适背景。
- 海报只采用明确简体/大陆地区标记或英文；通用zh不保证简体，缺少可靠标记时用英文，不回退到未知语言的默认海报。依据来源标记筛选，未加入OCR。
- 已有作品可在详情「更多操作 → 刷新资料」更新图片。图库确认无合规候选时清理旧图；网络失败保留缓存，不影响个人数据。
- minSdk21、v1签名、纯Java、SQLite schema1不变；开发证书沿用alpha.2。可覆盖alpha.2，不能覆盖签名丢失的alpha.1；旧版有数据时不要直接卸载。
- 夸克账号目录自动匹配、WebDAV与播放仍未移植/实现，长虹实机、真实TMDB Key仍待验收。测试APK与合成凭据不进入交付APK。

# My Cinema TV 0.1.0-alpha.2

Android电视端第二个开发预览，新增完整模拟器回归并修复首版问题。电视本机独立管理收藏，Windows保持原有发布线。

- 修复勾选季后焦点跳回导航栏；批量导入部分失败后能保留选择与已完成项继续重试。
- 修复从专题编辑框删除专题后，旧编辑窗口仍留在屏幕上的问题。
- 修复开发签名缓存路径未生效，显式指定Keystore路径、校验并固定公开证书指纹；缓存缺失时拒绝悄悄生成替代签名。它仍是开发签名，不是长期生产签名托管。
- 增加真实界面操作链、504条收藏/500个图片缓存键、进程终止重开、模拟器内核重启，以及分辨率/内存参数报告。成功导入使用隔离HTTPS测试服务，真实互联网另测401，不冒充真实账号搜索导入成功。

- **minSdk 21、v1签名、DEX035、纯Java无原生库**，目标覆盖长虹55D2S的Android5.1/API22、32位armeabi-v7a。交付可从U盘安装的单APK。
- 独立TMDB配置与加密保存、搜索与分季导入、SQLite本地收藏、图片缓存、个人评分/状态/短评、系列与专题、资源记录、本机备份恢复及遥控器操作。
- 已通过API22模拟器中的安装启动、配置界面验证保存、搜索/分季导入/图片下载、评分短评、批量部分失败重试、专题/资源/筛选、备份恢复、断服务后离线浏览、杀进程/模拟器整机重启后的保留检查；真实HTTPS调用收到无效测试Key的401响应。
- 真实Key完整搜索导入、长虹实机安装/遥控器/中文输入法仍待验收。界面报告使用受控收藏、占位海报及合成背景，不代表真实影视图片。应用初始没有测试收藏或凭据。
- 夸克账号目录自动匹配、WebDAV与视频播放尚未移植/实现。下一阶段接WebDAV资源，再验证老电视的真实解码、音轨字幕、拖动与续播。

下载`My-Cinema-TV-0.1.0-alpha.2-debug.apk`；配套`BUILD.json`和`SHA256SUMS.txt`记录来源、大小与校验值。用户交接中的安装通道为：**信号源 → 媒体中心 → U盘 → APK**。

这是**debug开发签名预览**，先用于体验与验收。alpha.1的默认签名未保存，本版无法直接覆盖alpha.1；若旧版已有收藏，请保留原安装，不要为了更新而直接卸载。新开发签名的公开指纹为`0e343d7d8d91f931b0350b7c01f87115f2fc7daf6402c0baee8276ced4a9bd44`，后续构建必须匹配。缓存不是长期托管，进入长期使用的beta前仍须固定私有发布签名及备份。

卸载会清除应用私有收藏、图片及本机备份；目前尚无跨设备备份包。本版适合干净安装的模拟器/设备测试，不作为唯一收藏副本。
