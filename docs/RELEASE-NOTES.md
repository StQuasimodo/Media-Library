# My Cinema v1.3.0-beta.1

本版同步更新 Windows 与独立 Android TV 客户端的收藏整理、图片和更新流程。

- 设置新增自动检查更新、预览渠道与可配置 HTTPS 镜像；GitHub失败后回退镜像。更新清单使用应用内公钥验证，安装包须通过 SHA-256 校验；安装前保留本地备份。Windows安装包尚无 Authenticode 签名。
- 夸克重新登录保留已选目录、匹配关系及自动处理偏好；主动断开账号仍可清理连接配置。
- 影视库新增系列文件夹视图，可将关联剧集与衍生电影放入同一影视宇宙，支持手动归类和移出。原海报墙、同系列聚合和季序保留，并调整海报墙间距与焦点。
- 自动背景只采用该季图库中的合适横图，不再按季轮换整剧图片；缺少时使用该季海报氛围。支持手动选择/锁定海报和背景，刷新保留选择。全剧图片须人工确认季份。仍按图库标记判断，不声称能自动识别所有宣传图/剧照。
- 详情增加在线剧照入口；仅在内存展示，不写入本地图片缓存。

首次须手动安装此版本，以后可在应用中检查更新。镜像默认留空，可配置 HTTPS 前缀或含 `{url}` 的模板；此版本没有内置第三方镜像。保留原数据库结构、应用身份、个人记录和凭据格式。

电视端同期版本为 0.3.0-alpha.1，minSdk21/ARMv7 保留，播放器仍为 LibVLC3.7.7。本次不新增解码能力，不将模拟器测试当作长虹实机验收。
