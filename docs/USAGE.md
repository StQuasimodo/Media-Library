# 安装与使用

[返回项目首页](../README.md) · [文档目录](README.md)

## Windows 安装

需要 Windows 10 / 11 x64。若已有构建好的发行产物，可运行 `release/INSTALL.cmd`，或使用 `release/RUN-PORTABLE.cmd` 启动免安装版。源码仓库不保证包含这些产物；自行构建见[开发与打包](DEVELOPMENT.md)。安装失败见[故障排查](TROUBLESHOOTING.md)。

1.2安装器提供可取消的「创建桌面快捷方式」选项，并记住选择；取消后重装不应再强制创建，开始菜单仍可启动应用。正式窗口不再显示原生「编辑／视图」菜单栏。

## 配置 TMDB

1. 到 <https://www.themoviedb.org/settings/api> 免费申请 API Key（v3 Key 或 v4 读取令牌均可）。
2. 应用内「设置 → 影视元数据」粘贴 Key，点「保存并验证」——会真实请求一次 TMDB 后才保存。
3. 「添加影视作品 → 搜索 TMDB」输入片名，从真实结果中挑选，确认后才会写入本地。剧集点击「选择季」，展开各季海报、年份、简介与集数，可逐季确认或勾选多季导入，也可选择「收藏整剧」。

beta.2 rev2补齐普通搜索的季选择：批量导入默认“想看”，已收藏季会标记并跳过，个人评分不被覆盖。部分失败时已保存的季保留，可重试剩余项。季列表下方可手动补季，进入预填标题的手动表单；整剧搜不到仍可直接手动添加。手动补录保存为独立手动条目，不冒充TMDB资料。季简介会尝试英文回退，仍缺失时明确显示缺失，不使用整剧简介代替。

实现要点：

- 请求地址优先 `https://api.tmdb.org/3`，失败自动回退 `https://api.themoviedb.org/3`（部分网络只放行其一）。
- 超时 12 秒；401 → Key 无效；429 → 限流；404 → 无此资料；网络错误与超时分别给出中文提示。
- 中文简介为空时自动回退一次英文，避免详情页空白。
- 导入时同步下载海报（w500）与背景图（w1280）到本地缓存；**下载失败不会导致导入失败**，界面会提示「图片未能缓存」。
- 「刷新 TMDB 资料」只更新外部字段与图片，评分、笔记、收藏理由、专题、夸克资源都不受影响。
- Windows1.3预览 / 电视0.3预览起，分季背景只自动采用本季图库的横图；缺失时使用本季海报氛围，不再轮换整剧图库。详情可选择海报/背景并锁定，整剧图片明确提示需要人工确认季份。在线剧照仅在内存浏览、不保存本地。海报仍只采用明确简体/大陆标记或英文，未做OCR。

API Key 保存后不会回显。状态为「已配置」且输入框为空是正常情况，无需因更新或重启重新填写。v1.1.0 起区分「未配置」「凭据存储暂不可用」和「已保存，读取失败」；后两种状态保留原文件，可点击「重新读取已保存的配置」。需要核对目录时，该区域会显示当前数据目录并提供打开按钮。

本产品使用 TMDB API，但未获得 TMDB 的认可或认证。

## 应用内更新（Windows1.3预览 / TV0.3预览）

首次手动安装包含更新功能的版本后，在「设置 → 应用更新」检查与下载。Windows默认启动后检查、之后每12小时检查；电视启动时检查，12小时内不自动重复。不会自行关闭应用安装。Windows选择「退出并安装」后启动安装器，电视端交给Android系统确认。

beta.2 / TV0.3-alpha.2起可在设置直接选择GH-Proxy、GHFast或ghproxy.net；自动模式先尝试GitHub，失败后按顺序尝试三个内置站点。也可选择仅GitHub或保存自定义HTTPS镜像。支持 `https://镜像域名/` 前缀（拼接完整原地址）或 `https://镜像域名/?url={url}` 模板（替换为编码后的地址）；需镜像同时代理raw.githubusercontent.com更新清单及GitHub Release文件。新配置默认自动回退，已有自定义/仅GitHub设置保留。更新清单签名和文件哈希必须通过，电视还校验包名、版本与现有安装签名；镜像不接收影视库、API Key或夸克凭据。Windows更新清单签名不等于安装包已有Authenticode签名。

预览版Windows默认接收预览渠道，可关闭「接收开发预览版」；不会降级安装。TV开发预览使用预览渠道。电视安装来源权限由系统控制，不能绕过；长虹旧系统安装器仍需实机确认。

## 影视宇宙文件夹

影视库选择「系列文件夹」，打开文件夹查看相关作品。原「海报墙」和同系列聚合保留。TMDB电影系列/同剧各季自动归组；明确的跨作品关系（当前内置绝命毒师/风骚律师/续命之徒）进入同一宇宙。其他衍生关系通过「整理系列文件夹」选择作品，填写同一名称或已有文件夹名称。Windows支持搜索后批量选中；电视使用遥控器多选。移出宇宙不会删除作品、改变原系列或季顺序。

重新登录夸克会保留目录、已确认匹配和偏好；主动「断开」仍会清理连接选择。若更换账号后原目录不可访问，应重新选择账号中存在的目录。

## 影视库全部刷新（1.2.0）

在影视库工具栏点「全部刷新」，先重读已选的夸克目录，更新新增/消失文件、名称规格与增量关联，再依次刷新整个影视库的TMDB资料和图片。当前搜索、年份、状态、专题和系列筛选不限制刷新范围。夸克自动导入沿用设置中的偏好，歧义匹配可回设置确认，不因全部刷新强制采用。

进度区显示阶段、更新/失败/跳过，失败作品可展开查看；文字资料成功而图片库/下载失败时单独显示「图片待重试」，已有缓存保留。手动收藏、缺少外部标识、未配置凭据或未选目录会跳过并说明。凭据失效、限流、网络或服务错误会暂停后续TMDB请求，之后可再次刷新；已完成项保留。

切换页面不会中断任务，完成后相关页面会更新。点「停止刷新」会等待当前请求结束并丢弃未提交的迟到结果；退出应用也会停止本次任务，下次可重新刷新。期间暂不允许恢复数据库、切换夸克账号/目录、修改TMDB Key或编辑影视元数据，避免并发覆盖；个人评分/短评、专题和资源关系保持。

仅更新指定目录与元数据，不探测手动分享链接是否有效，不删除收藏。旧版官方工具已配置的只读目录也会读取；未配置的来源不会自动启动登录。

## 夸克自动匹配（1.2）

1.2预览版支持指定目录递归读取、TMDB自动匹配、确认后关联收藏和增量更新，也识别名称中的画质、编码、音轨等资源规格。beta.2起各季独立分组，选择TMDB整剧后读取季资料并独立收藏；搜不到的作品可在分组中直接手动创建并关联。设置步骤、自动导入选项和识别边界见[目录自动匹配指南](QUARK-MATCHING.md)。1.1.0只有登录与目录浏览，不包含自动匹配。

rev3当前使用schema v4。升级前会保存原数据库一致快照，见数据目录下 `backups/pre-migration-v3-*.db`（从1.1.0升级则为v2）。旧版不能直接打开v4库；保留新库后才可用升级前快照回退。API Key存储与应用数据目录不变。

## 系列分类与海报墙（beta.2 rev3）

影视库工具栏的「全部系列」可切换到某一系列；「同系列聚合」默认开启并记住选择。组内按序号从小到大排列，系列之间沿用所选排序。专题详情也会聚合系列。系列识别优先用TMDB电影系列/整剧身份，再辅助读取明确标题序号；没有明确编号时用上映顺序补位。没有序号与官方关系时不猜测，可在作品详情的「编辑影视资料」填写系列名称和序号。自定义系列会在刷新资料时保留。

已有TMDB电影会在后台补充系列信息，需已配置API及可用网络；保存后可离线使用。无Key或失败时仍可按明确标题/季数归组。新增schema v4保存系列信息，升级前自动生成`pre-migration-v3-*.db`（或v2）快照；旧应用不能直接打开v4库，回退应先保留新库并使用旧快照。

## 夸克资源

原有分享资源记录仍支持：资源名称、分享链接（http/https）、可选提取码、清晰度 / 版本 / 字幕 / 音轨、备注、状态（未检查 / 可用 / 不可用）。

- 应用**不会**访问、解析、下载或验证链接，也不会自动把状态标成「可用」。
- 「复制链接」写入剪贴板；「打开」经协议校验后交给系统默认浏览器。
- 删除一条资源只删除该记录，作品与收藏条目保持不动。

v1.1.0 已提供「设置 → 夸克网盘 → 关联夸克账号」：在独立的官方网页窗口完成登录，回到设置点击「检查连接」，验证通过后「浏览云端目录」。无需安装 Skill 或复制 Cookie。旧版 v1.0.0 不包含这一入口；最新版本下载及验收步骤见[网页登录接入](QUARK-WEB-CHECK.md)。

1.1.0网页登录接入可逐层浏览目录；1.2预览已加入递归同步、TMDB导入与收藏关联。真实账号目录访问与重启后继续访问尚待本机验收。原有官方工具桥接保留在「高级」区域，边界见[夸克目录接入](QUARK-FOLDERS.md)。

## 数据与备份

所有可变数据位于 Electron 的 `userData` 目录（默认 `%APPDATA%\My Cinema`），**升级应用不会清理数据**：

```
%APPDATA%\My Cinema\
├─ library.db            SQLite 数据库（影视资料 / 收藏 / 专题 / 夸克资源 / 设置）
├─ library.db-wal        WAL 日志
├─ images\               海报与背景图缓存（数据库只存相对路径）
│  ├─ poster\<2位散列>\<sha1>.png
│  └─ backdrop\...
├─ backups\              手动备份与恢复前的自动快照（pre-restore-*.db）
├─ exports\              JSON 导出
├─ logs\app.log          运行日志（已脱敏，滚动 2 MB）
├─ credentials.json      safeStorage 加密后的 TMDB API Key
└─ window-state.json     窗口尺寸 / 位置
```

- 卸载程序**不会**删除上述目录（`deleteAppDataOnUninstall: false`）。需要彻底清除时请手动删除该目录。
- 图片缓存丢失不影响收藏：数据库只保存相对路径，界面会自动回退为排版式占位图，重新获取元数据即可再次缓存。
- 备份可用 `VACUUM INTO` 生成一致性快照；恢复前会自动把当前数据库另存为 `pre-restore-*.db`，恢复失败自动回滚。
- 日志中的 API Key、JWT、`?pwd=` / `access_code=` 参数以及已登记的提取码都会被替换为 `[redacted]`。

网页登录会话保存在 `userData/Partitions/mycinema-quark-web` 的独立 Chromium 存储中，不包含在数据库备份内；「断开本机会话」仅清除此存储，不删除网盘文件，也不代表服务端撤销授权。不要上传此目录。

旧工具桥接的夸克源配置与可重建清单另存于 `quark-source.json` 和 `quark-inventory.json`，不包含在收藏数据库备份内；官方工具独立管理授权。

## 快捷键

| 快捷键 | 行为 |
|---|---|
| `Ctrl K` | 打开 / 关闭全局搜索（作品 + 页面跳转，支持 ↑↓、Enter） |
| `Ctrl F` | 跳转影视库并聚焦搜索框（在输入框内不抢占） |
| `Ctrl I` | 打开「添加影视作品」（在输入框内不抢占） |
| `Esc` | 关闭弹窗、搜索面板 |
| `Tab` / `Enter` | 在弹窗内循环焦点；Enter 激活当前操作 |
