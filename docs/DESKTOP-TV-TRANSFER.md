# 把电脑收藏与夸克整理结果迁移到电视

电脑端的“导出到电视”会保存收藏、评分、观看状态、短评、系列、专题、分享资源，以及当前夸克连接中已经扫描过的文件关联和忽略结果。无需在电视上逐个重复整理这些文件。

## 操作

1. 更新电脑和电视到支持迁移的版本（Windows 1.3.0-beta.7、TV 0.3.0-alpha.12及以后）。
2. 电脑「设置 → 数据与备份」选择 **导出到电视**，保存 `My-Cinema-Transfer-*.json`。
3. 将文件复制到U盘或电视可读取的位置。在电视设置选择 **从备份文件恢复**，选中迁移文件。
4. 老电视没有系统文件选择器时，用文件管理器将JSON复制到共享存储的 `Download/MyCinema`，选择 **从下载目录恢复**。
5. 电视会显示导入作品、关联和忽略文件数量。确认后合并收藏；相同TMDB作品复用电视已有身份，电脑的评分、状态和短评优先。电视独有作品、专题成员和两类播放进度保留。
6. 在电视连接与电脑相同的夸克账号，选择电脑使用的原影视目录，扫描一次。已有整理结果按原目录和文件ID生效；改过文件名但ID不变也无需重新匹配。忽略项会显示“已忽略匹配”。

导入不包含登录凭据、TMDB Key和图片缓存。已有电视配置保留；首次使用电视仍需配置所需账号与元数据服务，图片随后重新获取。迁移不要求电脑保持在线，也不访问、移动或删除网盘文件。

## 合并、重复导入与撤销

- 相同电影或同一季按TMDB身份合并，不会按相似标题把不同作品合在一起；手工作品按原始ID识别。
- 专题按已有ID或同名专题合并，成员取并集。相同作品的电脑记录优先，确认框会明确说明；重复导入不新增重复作品或专题。
- 导入关联先等待原目录的实际文件校验。选择其他目录不会把它们套用给相似片名。导入不会代替登录，也不会自动验证账号归属，请使用原账号。电脑整理过多个目录时，分别选择对应的原目录扫描。
- 后续在电视上手动更改关联或取消忽略后，以新的电视操作为准；再次主动导入同一电脑文件，则重新以该文件的记录为准。
- 恢复前生成完整 `before-restore.json`。需要撤销时，在电视选择 **恢复操作前备份**。再次恢复会更新这一份恢复点，重要备份仍应另行导出保存。
- 收藏、媒体关联及两类进度在同一联合事务中更新，任何阶段失败都回滚；写入安全副本失败时不开始修改。

“忽略”迁移覆盖电脑本次导出已知的文件ID，包括暂时消失但记录仍保留的文件。未来新出现的文件没有旧ID记录，仍按电视的正常扫描处理；电脑新增整理后可再次导出合并。未确认的搜索建议、其他已断开的账号历史和外部WebDAV地址不会冒充夸克关联导入。

## 文件格式与兼容

- 电脑SQLite `.db` 备份仍用于Windows恢复，不直接交给电视。普通 **导出JSON** 保留原存档格式，不含完整忽略结果，电视会提示使用“导出到电视”。
- 迁移文件使用 `my-cinema-export` / `formatVersion:2`，只含白名单数据和稳定文件标识。按当前连接scope导出各目录的关联／忽略，避免混入旧账号记录。
- 单文件最多8MiB，每类最多10000条。电脑先检查再写文件；电视在确认和写入前验证类型、版本、唯一身份与引用关系。合并后超限也会拒绝，保留原数据。
- 电视收藏数据库和媒体数据库schema均不变。含迁移状态或忽略标记的电视备份使用格式4，防止旧版格式1–3读取器静默丢失待确认的关联。新版继续兼容已有格式1–3；没有扩展数据时仍可生成格式3。
- 分享链接、提取码和文件名属于私人数据，请妥善保管迁移文件。Cookie、Token、密码、临时CDN地址和本机播放路由不会导出。

## 验证

桌面测试通过真实SQLite与生产导出服务生成 `tests/fixtures/desktop-transfer-v2.json`，Android instrumentation直接读取该文件。新增检查覆盖手动关联、忽略／消失后返回、目录不符拒绝激活、重复合并、保留电视独有数据与两类进度、备份往返、取消确认，以及媒体和云端阶段故障回滚。实际原生执行结果随交付记录补充；模拟器验证不代替用户真实账号和电视验收。
