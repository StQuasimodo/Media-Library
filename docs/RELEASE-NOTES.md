# My Cinema v1.3.0-beta.4

- 修正全剧横图回退：在质量接近的合格图片中按季稳定分配，候选充足时各季不再固定选同一张；真实本季图和手选图仍优先。图片顺序、单季/批量导入不影响结果。
- 不用低质图、海报或单集剧照硬凑差异；图库未标明季份时继续如实提示，合格候选不足仍可能复用。
- 读取原本遗漏的衍生作品合集ID关系，补充有来源依据的“神偷奶爸/小黄人”关系；未经确认的TMDB电影不再仅靠片名数字后缀自动合并，手动归属/排除优先。

## v1.3.0-beta.3

- 修复保存镜像后仍显示上一次更新检查超时的问题。保存本机设置不联网，并显示成功提示。
- 切换更新来源或渠道时取消旧检查，防止旧请求覆盖新状态；连接超时改为中文提示。
- 自动选横版背景：优先本季图库，无合适横图时回退全剧优质横图，注明“全剧通用横图 · 季份未标注”；背景区域不再使用竖版海报。
- 修复分季作品“恢复自动选图”后背景缓存范围丢失的问题。已有收藏可点击影视库一键刷新自动补图；手选锁定继续保留。
- 保留beta.2的内置镜像；收藏数据库、账号凭据、更新验签和安装包哈希校验不变。

## v1.3.0-beta.2

- 更新设置内置GH-Proxy（gh-proxy.com）、GHFast（ghfast.top）和ghproxy.net，支持自动回退、指定站点、仅GitHub或自定义HTTPS地址。自动模式只在GitHub失败后依次访问镜像。
- 保留已保存的自定义地址/仅GitHub选择；新配置默认自动回退。镜像不接收账号凭据，签名清单和完整安装包SHA-256必须通过。
- 已核对三站公开说明，并验证项目签名清单和APK1024字节Range与原包一致；这不是中国各运营商的速度测评，也不保证公共站点永久可用。

电视端同期0.3.0-alpha.2加入遥控器快捷菜单、免输入评分/状态、最近搜索、分组整理和焦点记忆；Windows保留原收藏、图片与数据库结构。

首次接入应用内更新的用户需要手动安装1.3预览；已安装beta.1可在「设置 → 应用更新」检查升级。
