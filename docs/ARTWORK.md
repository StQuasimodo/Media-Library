# 海报与背景选图

Windows 1.2.0-beta.3、电视0.1.0-alpha.3开始使用以下规则。原有收藏不会启动时批量覆盖图片；更新应用后，在详情页「更多操作 → 刷新资料」更新。评分、观看状态、短评、专题与网盘关联保持不变。

## 背景

旧规则使用本季第一张可用单集剧照，能区分各季，但没有保证构图适合作为大背景。现在从TMDB电影/整剧的`images`图库选横版背景，完全不读取`episodes[].still_path`作为背景候选。

- 至少1280×720，宽高比1.5～2.05；优先明确标为无语言的图片，再考虑英文背景。
- 结合尺寸、接近16:9的程度与平滑后的投票分排序，避免一次10分投票压过已有稳定评价。
- 取品质接近的前八张，按季数稳定分配；同剧图库不提供季归属，因此它们是同剧背景变体，不宣称对应某季。只有一张合适图片时各季可以共用，不硬凑低质剧照。
- 无合适横版时回退当前合规海报；海报也缺失则显示应用的无图状态。元数据尺寸与投票无法保证人物位置、留白、亮度及图片标记绝对正确，尚未增加图像构图识别或手选图库。

## 海报

只接受明确简体中文或英文的候选，简体优先。具体按图片元数据的简体文字体系标记、`zh-CN`或`zh`加明确`CN`地区信息判断；英文接受`en`。排除繁体、港台、通用`zh`和没有语言的海报。尺寸至少400×600，宽高比0.55～0.85。

TMDB常见API图片记录只有`iso_639_1: zh`，没有文字体系或地区，此时**自动使用英文**。网站图片详情虽可显示CN/TW/HK等地区，不能假定API一定返回同样的信息；未爬取网站作为应用运行时依赖，也未做OCR。规则只信任明确来源标记，不保证错误标注的图片能被识别。没有合规海报就保留无图状态，不借用默认`poster_path`绕过限制。

搜索预览和季列表也遵循规则，防止导入前先显示繁体。图库请求限制并发四个，短时缓存及失败冷却避免重复请求；元数据中文标题/简介的语言设置不变。

## 刷新与验证

图库查询成功且没有合规候选时，刷新会清除原有图片路径；图库请求失败或选定图片下载失败时保留原缓存，便于离线浏览。不会删除收藏、清空个人记录或修改数据库结构。
