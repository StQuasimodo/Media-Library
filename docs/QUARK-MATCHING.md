# 夸克目录自动匹配（1.2预览）

[使用指南](USAGE.md) · [验证与交付](VERIFICATION.md)

## 首次使用

1. 配置 TMDB API，在「设置 → 影视元数据」保存并验证。
2. 在「设置 → 夸克网盘」关联账号，在官方窗口正常登录。完成后点击「已登录，关闭窗口并检查」，或手动关闭所有网页登录窗口再检查连接。
3. 点击「浏览云端目录」，逐层进入自己的影视目录。点击「使用当前目录并开始匹配」，程序会递归读取完整范围，再查询 TMDB。
4. 可点击「确认 N 组高置信匹配」批量导入；其他资源可修改片名、年份和类型后重新搜索，选择候选并「确认导入并关联」。已有手动收藏可用「关联已有收藏」，无需重复导入。
5. 打开作品详情的「夸克网盘资源」查看实际关联文件、季集、规格、路径及上次读取时间。路径可复制，手动分享资源继续独立保留。

不要求创建分享链接、安装 Skill 或输入 Cookie。归并与匹配针对整部作品；同一电视剧多集/多季对应一部收藏，文件ID各自保留。

## 自动与增量

- 「启动时自动读取并匹配」保存到本地数据库；也可手动点「读取增量并匹配」。当前自动触发点是应用启动，不是常驻定时轮询。
- 「自动导入唯一高置信匹配」默认关闭。高置信要求规范化片名或原名一致、年份一致且候选唯一；同名、缺年份等情况需要确认。
- 已确认的同组新集数或版本会沿用原关联，即使暂时没有TMDB Key，也先完成这些已知关联；未知作品留待继续匹配。
- 按真实文件ID去重。改名可更新路径与规格；重复扫描不会重复创建收藏。电影与剧集的 TMDB ID 分开处理。
- 「忽略这组资源」会保留原收藏，但不再匹配此组；勾选显示已关联/忽略分组后可更改。更改匹配不删除旧收藏。
- 全部目录读取完成后才提交清单；失败、取消或超限保留上次完整清单。文件未再出现只标记为“当前目录未找到”，不判定已永久删除，也不删除收藏。
- TMDB请求失败会暂停未知项匹配，不连续重复请求。取消后等待当前请求结束，未完成导入不会在取消后提交；此前已完成关联保留。

## 文件规格识别

名称本身优先，其次最近的上级目录。缺失标记保留未知，不把目录大小或片名猜成视频参数；分辨率、编码等不是 TMDB 元数据。

| 信息 | 示例 |
|---|---|
| 分辨率 | 2160p/4K、1080p、1080i、720p、1920x1080 |
| 片源 | UHD Blu-ray、BluRay、WEB-DL、WEBRip、HDTV、BDRip、DVD |
| 视频编码/编码器 | H.265/HEVC、H.264/AVC、AV1、VP9、VC-1、MPEG-2、x264、x265 |
| 位深/动态范围 | 8/10/12bit、SDR、HDR、HDR10、HDR10+、DV/DoVi、HLG |
| 音频/声道 | TrueHD、Atmos、DTS-HD MA/HRA、DTS:X、DDP/EAC3、AC3、AAC、FLAC、LPCM，2.0/5.1/7.1等 |
| 语言/字幕 | 国语、粤语、英语等显式标记；CHS/CHT、简繁、中英双字、内封字幕 |
| 版本/其他 | REMUX、IMAX、导演剪辑、加长版，显式fps和Mbps/kbps；容器取自文件扩展名 |

例如 `The.Matrix.1999.UHD.BluRay.2160p.HEVC.TrueHD.Atmos.7.1.DV.REMUX.mkv` 会识别为1999年作品，并保留4K、UHD Blu-ray、HEVC、TrueHD/Atmos/7.1、Dolby Vision、REMUX与MKV标签。大小来自夸克目录接口，未知大小不会记为0。

这些是“文件名与目录识别”线索，可能被命名者误标。应用不会下载视频或探测实际码流，无法据此保证HDR、音轨或字幕真实存在。

## 会话与数据

- 网页窗口打开期间不能同步，避免登录过程中切换账号与任务交错。重新关联或断开会重置同步目录与自动导入选项，原收藏和历史文件记录保留；历史记录不会显示为当前连接。
- 数据库恢复后同步范围重置，需要重新选择，避免把备份中的旧范围当作当前会话。网页登录与API Key仍由独立本地存储管理。
- 新关联表位于 schema v3，与收藏一起进入SQLite备份；JSON归档包含关联作品ID、文件路径、规格等私人信息。
- 升级v2前自动保存一致快照。不要用旧版直接打开v3库；回退前保留新库与快照，避免覆盖新收藏。
- 每次扫描限制200个目录、32层子目录、20000项；单目录完整分页上限10000项。超限提示缩小范围，不返回伪完整清单。

## 验证范围

单元检查和真实Electron受控接口链路覆盖递归、候选确认、真实SQLite、图片缓存、剧集归并、跨类型ID、重启、增量、失踪文件、取消、歧义及连接隔离。受控数据不是个人账号成功记录。Windows安装器、包内容及本机真实在线验收以[验证说明](VERIFICATION.md)记录为准。
