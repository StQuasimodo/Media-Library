# My Cinema TV 0.1.0-alpha.1

首个Android电视端开发预览，电视本机独立管理收藏。原生界面沿用深色电影杂志配色、宽幅主视觉、横向海报轨、焦点联动及系列布局。Windows保持原有发布线。

- **minSdk 21、v1签名、DEX035、纯Java无原生库**，目标覆盖长虹55D2S的Android5.1/API22、32位armeabi-v7a。交付可从U盘安装的单APK。
- 独立TMDB配置与加密保存、搜索与分季导入、SQLite本地收藏、图片缓存、个人评分/状态/短评、系列与专题、资源记录、本机备份恢复及遥控器操作。
- 已通过API22模拟器的安装启动、真实Keystore、SQLite重开、受控TMDB业务和方向键/确认/返回检查；真实HTTPS调用收到无效测试Key的401响应。
- 真实Key完整搜索导入、长虹实机安装/遥控器/中文输入法仍待验收。界面报告使用受控收藏、占位海报及合成背景，不代表真实影视图片。应用初始没有测试收藏或凭据。
- 夸克账号目录自动匹配、WebDAV与视频播放尚未移植/实现。下一阶段接WebDAV资源，再验证老电视的真实解码、音轨字幕、拖动与续播。

下载`My-Cinema-TV-0.1.0-alpha.1-debug.apk`；配套`BUILD.json`和`SHA256SUMS.txt`记录来源、大小与校验值。用户交接中的安装通道为：**信号源 → 媒体中心 → U盘 → APK**。

这是**debug开发签名预览**，先用于体验与验收。开发签名缓存不是长期托管，进入长期使用的beta前须固定私有发布签名并备份；不能承诺更换签名后覆盖安装。卸载会清除应用私有收藏、图片及本机备份，尚未提供跨设备备份包。
