# My Cinema v1.2.0-beta.3

- 分季背景改用同剧的高清横版图库，不再选择首张单集剧照。优先无字、接近16:9且至少1280×720的图片；多个品质接近的候选按季稳定分配，数量不足允许共用，不用低质图片硬凑不同背景。图库不提供季归属，因此这些是同剧背景变体，不宣称对应某季宣传图。
- 海报仅接受明确简体/大陆地区标记或英文。TMDB的通用`zh`标签不区分简繁，缺少地区/文字体系信息时跳过并改选英文；不回退到未知语言的默认海报。筛选依据来源标记，未加入OCR文字识别。
- 搜索预览、季列表、导入、网盘自动匹配和刷新采用同一规则。已有作品请在详情页「更多操作 → 刷新资料」更新图片；成功查到图库但无合规图片时清除旧图，图库/下载失败保留已有离线缓存。
- 不改schema v4、数据目录或凭据格式；评分、短评、专题和网盘资源关联保留。Windows继续使用原应用身份，电视端独立发布0.1.0-alpha.3。
- 本轮自动化使用受控图库；公开《绝命毒师》图库/CDN另做匿名核对，不能代替真实TMDB Key在线验收。

# My Cinema v1.2.0-beta.2

## rev4 深色下拉菜单与分季背景修复

- 影视库与其他表单的下拉菜单展开后使用统一深色背景、浅色文字及克制的选中高亮，保留原生选择控件的键盘操作。
- 季收藏使用TMDB本季返回的首张可用单集横向剧照，不再继承整剧背景；缺少剧照时回退本季海报，两者都缺失则显示无图状态。整剧与电影的背景逻辑保持不变。
- 已有季收藏可在详情页执行「更多操作 → 刷新资料」替换共用背景；成功返回但没有季剧照时清除旧背景，让本季海报接替。图片下载失败仍保留已有缓存。
- 不修改数据库结构、数据目录或账号存储；评分、短评、专题和夸克资源关联保留。继续并入beta.2，新增rev4文件，保留此前资产与Tag。

## rev3 系列分类与海报聚合

- 影视库增加系列筛选，默认开启同系列聚合；系列内部按序号升序（1、2、10），系列之间保持所选排序。专题详情海报也按系列聚合。
- 剧集按TMDB整剧身份归组；电影优先使用TMDB系列与成员顺序，标题中的明确数字、中文和罗马序号用于辅助排列。无序号首部可与续集归组，不按相似前缀猜系列。
- 旧TMDB电影后台补充系列信息，保存后可离线分类；不改标题、评分、短评或资源。缺Key/网络失败仍支持本地标题/季数识别。
- 编辑影视资料可设置自定义系列名称和序号，刷新外部资料会保留手工系列。
- 需升级到schema v4保存系列信息；升级前自动生成pre-migration-v3-*.db（来自v2则为v2）快照。旧版不能直接打开v4库，回退前保留新库并使用升级前快照。API Key和账号存储路径不变。
- 继续并入beta.2，安装包等文件带rev3后缀，旧资产和原Tag保留。

## rev2 修订（应用户要求合并到beta.2）

- 普通TMDB搜索支持选择整剧后展开季列表，展示各季海报、年份、简介、集数与已收藏标记。
- 可单季确认并设置评分，或多选批量导入；已收藏季复用，部分失败保留已完成项并支持重试剩余季。
- 保留收藏整剧入口，季资料缺失时可预填标题转到手动补录。手动补录为独立手动收藏。
- 季简介/海报缺失会明确显示，不再使用整剧简介和海报冒充对应季资料。
- 应用版本号仍为1.2.0-beta.2，修订文件带rev2后缀；保留原始Tag与资产，BUILD-rev2.json记录实际修订源码和产物摘要。

## 原beta.2功能

- 同一剧的不同季独立归组；确认整剧候选后读取TMDB对应季的海报、简介与首播年份，保存为可独立评分、标记状态、刷新资料的季收藏。新增集数复用该季关联，旧版整剧关联保留，可通过「更改匹配」逐季重选。
- 搜不到或缺少季资料时，可直接在资源分组手动创建并关联收藏，无需TMDB Key；创建与文件关联在同一数据库事务完成。
- 季资源搜索不再把季年份当作整剧首播年份过滤，减少后续季搜不到的问题。

以下功能延续beta.1：

- 补齐夸克目录自动匹配：选择目录后递归读取，按片名、年份与季集归并，自动查询 TMDB；支持逐项/批量确认、关联已有收藏、忽略与改正匹配。
- 可启用启动时自动读取，以及自动导入唯一高置信结果。已确认剧集的新增集数复用原关联；缺年份或歧义结果留待确认。
- 保存云端文件ID与收藏关联，在作品详情查看文件、季集、路径和大小，无需手工创建分享链接。完整增量读取标记未找到文件，失败或取消不提交半份清单，不自动删除收藏。
- 识别文件名/目录中的分辨率、片源、H.264/H.265/AV1等编码、位深、HDR/杜比视界、音频与声道、语言、字幕、剪辑版本、帧率及显式码率。标记为名称识别线索，不等同于视频流探测。
- 修复 TMDB 电影/电视剧数字ID冲突及并行导入去重；保留个人评分、短评等字段。
- 使用用户指定的胶片山景图标，统一程序、窗口、快捷方式和安装器图标。正式窗口不再显示“编辑/视图”菜单栏。
- 安装器增加真正可取消的桌面快捷方式选项，并记住选择；重装不应重新强制创建，开始菜单入口保留。

本版本为预览版，不替换1.1.0正式版的 Latest。支持 Windows 10/11 x64，安装包未签名。下载 `My-Cinema-1.2.0-beta.2-Setup.exe` 或免安装ZIP。

首次升级到 schema v3 前会在数据目录的 backups 中保存 `pre-migration-v2-*.db` 一致快照，原数据库的收藏保留。1.1.0 无法直接打开 schema v3；若需回退，应保留新库后使用v2快照。API Key和网页登录存储不在数据库备份中，本次不更换数据目录。

自动验证使用受控目录/TMDB响应和隔离数据库；真实账号目录、真实带Key在线匹配及个人电脑上的完整升级仍需本机验收。应用不下载视频、不播放、不自动创建分享或修改网盘文件。
