# 视觉与交互规范

设计方向：**PS5 式沉浸浏览 + 电影杂志排版 + 私人放映室的克制**。PS5 是交互骨架，杂志是审美参照。

规则来源：产品视觉规范 + 2026-10-24 前端审计（见 AUDIT-2026-10-24.md）。修改界面之前先读这一页。

---

## 1. 设计原则

1. **画面是主体**：一张大幅背景图 + 一句标题，胜过一排卡片。
2. **焦点即内容**：海报轨上的选中项决定主视觉——不是装饰，是导航本身。
3. **一处强调**：全站只有冰蓝色一种强调色，只用于选中、焦点、主操作。
4. **结构承载信息**：分隔线、标签、编号只在编码信息时出现；不做纯装饰。
5. **静止优先**：动效只回答用户的动作（切换、打开、确认），不做自娱自乐的循环动画。
6. **克制收尾**：每个画面至少删掉一件可有可无的装饰。

## 2. 色彩令牌

| 用途 | 令牌 | 值 | 说明 |
|---|---|---|---|
| 空间背景 | `--bg-space` | `#101216` | 页面最底层 |
| 内容背景 | `--bg-content` | `#171a21` | 主内容区 |
| 侧边栏 | `--bg-sidebar` | `#1d222c` | |
| 悬停 | `--bg-hover` | `#282f3b` | |
| 输入框 | `--bg-input` | `#12161d` | |
| 主文字 | `--text-primary` | `#e9ecf2` | 对内容背景 14.7:1 |
| 次要文字 | `--text-secondary` | `#9299a6` | 6.08:1 |
| 三级文字 | `--text-tertiary` | `#868d9a` | **4.77–5.62:1（AA 合格）**；旧的 `#6d7482` 只有 3.39–3.99，已废弃 |
| 强调 | `--accent` | `#8ab4ff` | 8.33:1 |
| 危险 | `--danger` | `#e2776f` | 5.89:1 |
| 分隔线 | `--line` | `#353b47` | 仅用于控件描边 |

**使用规则**

- 蓝色只出现在：选中态、焦点环、主按钮、少量状态点。
- 卡片默认**无边框**，靠背景层次（`rgba(255,255,255,.018)`）与阴影区分；边框只给输入控件和临时浮层。
- 大面积背景图上方允许：渐变遮罩、轻微 `brightness(1.08)` 提亮、极小的暖/冷光晕。
- 禁止：蓝紫渐变墙、霓虹描边、发光按钮、每张卡片都带边框。

## 3. 排版

| 层级 | 用途 | 字号 | 字重 | 备注 |
|---|---|---|---|---|
| Hero title | 主视觉标题 | `clamp(38px, 3.4vw, 54px)` | 650 | 负字距 -0.02em |
| Film title | 详情页标题 | `clamp(32px, 2.8vw, 44px)` | 650 | |
| Section | 区块标题 | 18px | 600 | |
| Body | 正文 | 15px | 400 | 行高 1.8 |
| Meta | 元信息 | 12.5px | 400 | `tabular-nums` |
| Label | 结构标签 | 11px | 400 | 字距 `--tracking-label: 0.1em` |

**字体**

- 界面：`Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI → system-ui`
- 展示（仅 Latin）：`Iowan Old Style → Palatino Linotype → Georgia`
- 用法：中文标题用无衬线重字重；**原名、宣传语、短评**用衬线斜体/衬线块，形成杂志式的两层声音。
- 等宽仅用于：快捷键、分享链接、文件路径。

**明确不做**（模板化特征）

- 不给标题里的某一个词单独变色 / 加粗 / 斜体。
- 不做全大写的宽字距「eyebrow」小标签：中文标签保持句首大写语义，字距 0.1–0.12em，不再 `text-transform: uppercase`。
- 元信息不再用「A · B · C」中点串联，改为**1px 细分隔线**（`.meta-sep`）。
- 编号只出现在真实序列里（想看队列），不用于装饰。
- 行宽控制在 80 字符以内；正文块最大 620px。

## 4. 布局

首页采用独立沉浸外壳：

```text
整窗电影背景
├─ 顶部：品牌 / 首页、影视库、专题、想看 / 搜索、添加、设置
├─ 上方：最近收藏的横向焦点轨道
├─ 下方：片名、原名、个人状态、元信息、作品入口
└─ 首屏之后：专题选辑 / 想看队列
```

- 首页不显示固定侧栏，导航覆盖在背景上；滚动后导航底色变实。内容两侧留白使用clamp(32px,5vw,88px)。
- 背景首屏至少680px，正常高度铺满100svh。高度≤800px时收小轨道并隐藏简介，保留片名和主要操作。
- 标题优先中文衬线字体，使用系统已有字体；Windows与Linux字体回退会有差别，仍需Windows视觉验收。
- 首页主操作为米白色圆角按钮；键盘焦点沿用冰蓝色。保留真实空状态，不补演示收藏。
- 影视库、专题管理、设置仍采用侧栏和常规内容区；详情/专题详情沿用此前沉浸改良布局，本轮不宣称已统一完成。
- 列表页保持1560px可读宽度，网格海报2:3，既有筛选与操作不变。

## 5. 聚焦交互（PS5 模型）

| 元素 | 默认 | 悬停 | 聚焦 | 选中 |
|---|---|---|---|---|
| 首页轨道海报 | 小尺寸、低对比 | 切换当前作品 | 同步选中＋冰蓝轮廓 | 固定槽位内变大、浅色细轮廓，不挤动整页 |
| 网格海报 | 阴影 | 1.02 倍 + 淡蓝描边 | 2px 冰蓝 outline + 3px offset | — |
| 导航项 | 次要文字 | 背景 `--bg-hover` | 同上 + 焦点环 | 背景 `--accent-wash` + 左侧 2px 蓝条 |

- 轨道使用 roving tabindex：只有选中项 `tabIndex=0`，`←/→/Home/End` 移动并同步主视觉，`Enter` 打开详情。
- 主视觉切换：背景 **300ms** 交叉淡入（新图先解码），文案 280ms 淡入上移 10px；不改变页面布局。
- 相邻两项的背景图在切换前预加载，切回已看过的作品不再请求。
- 减少动效时：所有过渡被压到 1ms，交叉淡入退化为直接替换。

## 6. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 海报悬停 / 聚焦 | 160ms | `cubic-bezier(.2,.7,.3,1)` |
| 导航切换 | 140ms | 同上 |
| 页面切换 | 200ms | 同上（淡入 + 6px 上移） |
| 主视觉文案 | 280ms | 同上 |
| 背景交叉淡入 | 300ms | 同上 |
| 弹窗出现 | 170ms | 缩放 0.99 + 上移 10px |

- 优先对transform / opacity做动画；首页焦点海报在固定槽位内过渡尺寸，不改变轨道总高度。
- 不使用弹跳、旋转、粒子、循环动画。
- `prefers-reduced-motion` 与「设置 → 动效」都生效：`html[data-motion='reduce']` 把时长压到 1ms。

## 7. 组件约定

- **按钮**：`btn-primary` 仅用于每屏一个主操作；`btn-secondary` 用于次要；图标按钮必须有 `aria-label` + `title`。
- **弹窗**：`role="dialog"`、`aria-modal`、焦点陷阱、`Esc` 关闭、打开时聚焦第一个可聚焦元素、关闭后还原焦点。
- **表单**：标签在上、错误在字段下方、`aria-invalid` 标记无效态；两列表单用 `.form-grid.cols-2`，跨列用 `.span-all`。
- **空状态**：说明「为什么空」+ 一个真实入口；不用虚线大框装饰。
- **状态标签**：资源状态默认「未检查」，永不自动标记为可用。
- **图标**：统一 24×24 viewBox、`stroke="currentColor"`、`stroke-width 1.7`、圆角端点；不使用 emoji。

---

## 8. 可访问性

- 焦点可见：全局 `:focus-visible` 2px 冰蓝环；自定义组件（海报、轨道）用等价的 outline。
- 对比度：正文 ≥ 4.5:1，三级文字已提到 4.77:1 以上。
- 键盘：所有操作可达；弹窗有焦点陷阱；轨道有方向键。
- 语义：导航 `aria-current="page"`；轨道选中项 `aria-current="true"`；分段控件 `aria-pressed`。
- 头像/海报图片：装饰性 `alt=""`；海报容器用 `aria-label` 给出片名。
- 动效可关闭。

---

## 9. 页面结构要点

**首页**：整窗背景内：顶部导航 → 上方聚焦轨道 → 下方电影信息；首屏之后是专题与想看。空收藏时：排版式主视觉 + 添加/配置入口 + 一行说明。

**详情页**：全幅主视觉（背景 + 海报 + 标题 + 2 个操作 + 图标组）→ 我的记录（理由 / 短评）→ 简介 → 夸克资源；右栏评分、观看状态、专题、资料信息。无图作品使用渐变主视觉，不留空白。

**影视库**：工具栏（搜索 + 3 个筛选 + 排序 + 数量 + 添加）→ 海报网格 → 空/错误状态。

**专题**：卡片墙（封面马赛克）→ 详情页按专题展示收藏。

**想看**：编号队列行，快速切换观看状态。

**设置**：左锚点导航 + 元数据 / 夸克目录 / 外观 / 数据 / 关于，只放真实生效的选项。
