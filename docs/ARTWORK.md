# 海报与背景选图

Windows1.3.0-beta.4 / TV0.3.0-alpha.4采用以下规则。保留原收藏数据和数据库结构。[开源实现调研与取舍](OPEN-SOURCE-ARTWORK-COLLECTIONS-2026-11-11.md)。

## 季背景的来源

优先采用本季图库中满足尺寸要求的横图。TMDB季图库常只有海报；缺失时按用户授权自动选全剧优质横图，注明“全剧通用横图 · 季份未标注”。不按季号轮换全剧图库，不读取`episodes[].still_path`作为背景，也不把竖版海报填入背景。所有横图都缺失时显示暗色空间背景。

本季自动缓存为`backdrop/season/<剧集ID>-<季号>/...`，全剧回退为`backdrop/series/<剧集ID>/...`，手选保持`backdrop/manual/...`。全剧回退从去重、质量分与最佳差不超过8分的合格候选中按季稳定分配；正常季顺序选取，特别篇优先末位。候选足够时不固定每季第一张，候选不足会复用；不以低质图强行制造差异，也不冒充本季专属。

其他剧集不能借用这些缓存。旧收藏点击影视库一键刷新可重新自动选图，手选锁定继续保留；需要重新推荐时点“恢复自动选图”。分配比较的是实际图片，不只是生成不同缓存路径。[规则与测试](SERIES-RELATIONSHIPS.md)。

电影/整剧采用自身图库。横图至少1280×720，比例1.5～2.05，结合分辨率、接近16:9程度和平滑投票排序。明确标记为英文的横版图优先于无语言图，作为宣传图的保守启发；这不能证明图片一定是宣传物料。没有OCR或构图识别，不声称自动排除所有普通剧照。

## 手动选择与锁定

详情「更多操作 → 选择海报 / 选择背景宣传图」预览候选。分季背景额外提供明确标记为「全剧图库 · 季份未标注，需人工确认」的横图。选择后锁定，刷新元数据保留；缓存丢失时可按原TMDB图片标识重新下载。点击「恢复自动选图」取消锁定。图库暂不可用时不会以空结果覆盖现有选择。

自动季图与手选路径使用已有图片相对路径保存来源和锁定，不新增数据库迁移。单纯复制数据库不包含图片；刷新可重建允许的图片缓存。

## 海报语言

只接受明确简体中文或英文，简体优先。接受`zh-Hans`、`zh-CN`或`zh`加明确`CN`地区；英文为`en`。排除繁体、港台、通用`zh`和无语言海报，至少400×600、比例0.55～0.85。没有合规候选时不借用默认`poster_path`。搜索预览、季列表和手选图库均遵循规则。

TMDB常只提供`iso_639_1: zh`，不能据此认定简体；来源标记错误仍可能导致误选。图库并发、短时缓存和错误冷却保留，元数据标题/简介语言不受影响。

## 在线剧照

详情「在线剧照」独立于背景选择。分季从该季的集资料读取剧照标识；电影/整剧浏览其横版图库。Windows通过受限`mycinema://transient/`协议获取固定TMDB图片域，响应`no-store`；电视关闭URL磁盘缓存、直接解码到受限内存。剧照不写入图片目录或收藏数据库，不进入备份。

剧照没有离线浏览；关闭或切换后回收视图引用。手选成为海报/背景的图片属于用户明确选择的缓存，仍可离线展示。

## 验证范围

单元测试覆盖错误季背景、自动季来源、手选保留与缓存重建、静态语言筛选，以及在线剧照的无凭据/不落盘响应。Windows真实Electron、API22模拟器验证另见本次验收报告。真实TMDB账号、来源图片标记和目标电视显示效果仍需实机验收。
