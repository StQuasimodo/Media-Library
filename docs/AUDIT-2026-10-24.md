## 一、可访问性

### A1 三级文字对比度不足（严重）

`--text-tertiary: #6d7482` 在应用各表面上只有 **3.39–3.99:1**，用于提示文字、时间戳、计数等真实内容，低于 WCAG AA 的 4.5:1。

实测（相对亮度计算）：

| 前景 | 空间背景 | 内容背景 | 侧栏 | 悬停 |
|---|---|---|---|---|
| `#6d7482` 旧值 | 3.99 | 3.71 | 3.39 | 2.87 |
| `#868d9a` 新值 | 5.62 | 5.22 | 4.77 | 4.03 |

处理：令牌改为 `#868d9a`，并在 `tokens.css` 注释中记录原因，避免以后被人改回去。

### A2 海报轨的 ARIA 角色不匹配

原实现用 `role="listbox"` + `role="option"` 包裹 `button`。listbox 的子项应是 `option` 而非可聚焦按钮，屏幕阅读器行为不可预期。

处理：改为 `role="group"` + `aria-label`，选中项用 `aria-current="true"`；键盘交互（方向键 roving tabindex）不变。

### A3 弹窗焦点

- 初始焦点落在关闭按钮（X）上，用户需要多按一次 Tab 才能输入。
- 焦点陷阱在打开瞬间只查询一次可聚焦元素；导入对话框是异步加载结果，后续出现的按钮无法通过 Tab 抵达。

处理：
- 初焦优先选择第一个 `input/textarea/select`，没有才退到第一个可聚焦元素。
- Tab 时重新查询可聚焦元素集合。

## 二、视觉语言（模板化特征）

依据 frontend-design 列出的「生成式默认」清单逐项核对：

### V1 全大写 + 宽字距的小标签（已改）

`.eyebrow`、`.hero-eyebrow`、`.film-eyebrow`、`.panel-title`、`.fact-title`、`.film-section-head`、`.record-block-title`、`.nav-label`、`.brand-subtitle`、`.collection-count` 共 10 处使用 `text-transform: uppercase` + `0.14–0.18em` 字距。

处理：删除 `uppercase`，字距收敛到 `--tracking-label: 0.1em` / `--tracking-eyebrow: 0.12em` 两个令牌。中文标签因此更像编辑排版，而不是套模板的 eyebrow。

### V2 元信息用中点串联（已改）

`A · B · C` 的元信息链是典型模板写法。改为 1px 细分隔线（`.meta-sep::before` 与 `.rail-meta .dot`），读起来像杂志的日期栏。

### V3 保留的判断

以下「模板特征」在本项目里是**规范要求或真实语义**，因此保留：

- **近黑背景**（`#101216` 等）：视觉规范明确指定，brief 优先。
- **想看队列的 01/02 编号**：内容确实是排序序列，编号承载顺序信息。
- **等宽字体**：仅用于快捷键、分享链接、文件路径，属于代码/标识符的正确用法。
- **每页 200ms 的入场**：规范要求页面过渡 160–220ms，且只作用于页面容器一次。

## 五、未处理项（有意为之）

| 项 | 原因 |
|---|---|
| 80 处内联样式 | 多数是单次布局微调（列宽、最小高度）；只有重复模式（跨列）被抽成类。继续抽取会制造一次性工具类，反而降低可读性 |
| 模块级 CSS（非 CSS Module） | 个人应用规模可控，类名统一前缀 + 单文件分区已足够；引入 CSS Module 会增加构建复杂度 |
| 虚拟滚动 | 个人收藏量级（数百部）不需要 |
| i18n | 产品仅中文；文案集中在 `lib/format.ts` 与页面内，未来抽取成本可控 |
| 真实 TMDB 图片下的取景 | 本机无 Key，无法验证真实剧照的裁切；已把 `background-position` 与遮罩做成易调参数 |
