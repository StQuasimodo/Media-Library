# 需求说明

状态标记：`[x]` 已实现并验证 · `[~]` 已实现但受环境限制未做端到端验证 · `[ ]` 未实现。

## 1. 产品定位

2026-10-27新增Android电视端范围见第14节；下列不播放/不下载的既有边界描述当前Windows版，不限制已授权的电视端后续播放阶段。

`[x]` 私人影视收藏库：展示收藏、整理专题与观影记录、登记夸克网盘资源位置。

`[x]` 仅供开发者本人使用；单机、无账号、无云同步、无商业化。

`[x]` 不是播放器 / 下载器：不下载或播放网盘视频；允许通过官方授权工具只读指定目录清单。

**边界（明确不做）**

- `[x]` 不支持其他网盘，不为多网盘设计插件层
- `[x]` 不接受夸克密码或 Cookie；账号 OAuth 授权由官方工具独立管理，不调用未公开接口
- `[x]` 不检测分享链接有效性、不自动创建分享、不播放、不下载
- `[x]` 不做本地媒体扫描与本地播放器
- `[x]` 不做账号系统、多用户权限、云端数据库

## 2. 功能要求

### 2.1 影视资料管理

- `[x]` 添加影视作品（TMDB 搜索导入 + 手动录入两条路径）
- `[x]` 搜索外部资料、展示候选（标题/年份/海报）、用户确认后才写入
- `[x]` 编辑本地影视资料（标题、原名、年份、类型、片长、类型标签、宣传语、简介）
- `[x]` 查看详情、删除收藏条目
- `[x]` 重复导入检测（同一 TMDB id 不产生第二个条目，返回既有条目）
- `[x]` 内部主键为 UUID，第三方 ID 只存在 `external_id` 列
- `[x]` 一部作品只有一个收藏条目，但可属于多个专题、关联多条资源
- `[x]` 电影与剧集分别展示各自可得的字段（`runtime` vs `episode_run_time`）

### 2.2 个人收藏信息

- `[x]` 个人评分 0–10（0.1 步进）
- `[x]` 观看状态：想看 / 观看中 / 已看完 / 暂不观看
- `[x]` 收藏时间、可选观看时间
- `[x]` 收藏理由、个人短评
- `[x]` 收藏排序（`sort_order`，并在列表层提供 7 种排序）
- `[x]` 这些字段永不被外部元数据刷新覆盖

### 2.3 夸克网盘资源

- `[x]` 新增 / 编辑 / 删除资源记录
- `[x]` 资源名称、分享链接、可选提取码
- `[x]` 清晰度、版本、字幕、音轨、备注
- `[x]` 复制分享链接 / 复制提取码；用系统默认浏览器打开
- `[x]` 一部作品关联多条资源
- `[x]` 状态可为「未检查 / 可用 / 不可用」，**默认未检查**
- `[x]` 删除资源不删除作品与收藏条目

### 2.3.1 指定云端文件夹（2026-10-24 更新边界）

- `[~]` 用本机已安装且授权的夸克官方工具浏览目录与读取视频清单，真实账号待验收
- `[x]` 读取完整分页结果文件，不把前5条预览误作全量；不完整结果不保存
- `[x]` 可选包含子目录，循环去重、范围限制、取消、失败保留旧清单
- `[x]` 独立保存已选目录与启动时自动读取设置；文件名识别作为线索，不当作已确认元数据
- `[ ]` TMDB自动匹配、云端文件与影视作品的稳定关联、增量入库（不以手动分享链接代替云端文件身份）

### 2.4 专题

- `[x]` 创建、编辑（名称/描述）、删除
- `[x]` 加入 / 移除作品；同一作品可在多个专题
- `[x]` 删除专题不删除影视作品
- `[x]` 专题名称唯一（大小写不敏感）

### 2.5 检索与浏览

- `[x]` 标题 / 原名 / 简介 / 收藏理由 / 短评的全文匹配（LIKE，转义 `%` `_`）
- `[x]` 年份、观看状态、专题筛选
- `[x]` 排序：最近收藏、最早收藏、标题 A→Z、标题 Z→A、年份新→旧、年份旧→新、评分高→低
- `[x]` 加载 / 无结果 / 错误 / 空状态

## 3. 数据与持久化

- `[x]` SQLite 单文件；重启后数据存在
- `[x]` 版本化迁移（`schema_migrations`），迁移在事务内执行

- `[x]` 重要写入使用事务（导入 = 作品 + 条目）

**数据隔离**

- `[x]` 刷新元数据不覆盖评分 / 理由 / 短评 / 专题 / 资源
- `[x]` 删除专题不删除作品
- `[x]` 删除资源不删除作品
- `[x]` 删除收藏条目会清理其专题关联与资源记录（并在确认框中明确告知）
