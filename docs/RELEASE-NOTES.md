# My Cinema v1.1.0

- 新增应用内夸克网页登录入口：设置 → 夸克网盘 → 关联夸克账号 → 检查连接 → 浏览云端目录。无需另开验证工具或手动复制 Cookie；原工具桥接保留在高级选项。
- 修复 TMDB 凭据读取或解密失败被误报为「未配置」并缓存的问题。新增重新读取操作，保留原文件；已配置的密钥不回显，无需因输入框为空重新填写。
- 保留原有收藏、元数据、图片缓存、专题、备份与 SQLite schema v2，继续使用同一用户数据目录。
- 新增版本管理规则、发布前版本检查，以及旧版到新版的 Windows 真实加密凭据兼容验证。

Windows 10 / 11 x64：安装 `My-Cinema-1.1.0-Setup.exe`，或解压 `My-Cinema-1.1.0-portable-win64.zip` 后运行 `My Cinema.exe`。可选的 `INSTALL.cmd` / `RUN-PORTABLE.cmd` 与对应产物放在同一目录，校验文件为 `SHA256SUMS.txt`。

夸克网页登录仍处于实际账号验收阶段，当前支持逐层只读浏览；指定目录自动同步、TMDB 匹配入库与收藏关联尚未完成。真实账号读取、实际登录重启保持、带 Key 的完整 TMDB 在线链路及个人电脑安装/缩放仍待验收。凭据测试使用合成值，不代表已恢复用户本机的旧配置。

应用不提供播放或下载功能。安装包未签名；升级前可在设置中备份收藏数据库。
