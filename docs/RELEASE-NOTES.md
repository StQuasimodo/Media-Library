# My Cinema v1.2.0

Windows正式版，汇集1.2预览阶段的夸克目录匹配、分季收藏、系列海报墙与图片筛选，并新增影视库「全部刷新」。

- 影视库工具栏一键刷新：先更新已选夸克目录、画质编码等规格及增量关系，再刷新整个收藏库的TMDB资料与图片，不受当前筛选影响。沿用已配置的自动导入偏好，歧义候选仍需确认。
- 显示阶段、进度、失败/跳过及失败作品；图片下载不完整单独显示「图片待重试」，保留旧缓存。切换页面后继续，可停止并保留已完成更新；限流、凭据失效、网络/服务异常会暂停后续资料请求。
- 保留评分、短评、收藏理由、专题、手工系列和已确认资源关联。未配置TMDB、未选夸克目录或手动收藏会明确跳过；不验证手工分享链接有效性，不自动删除收藏。
- 夸克应用内连接、指定目录递归读取、候选确认/自动导入、增量关联，以及文件名中的分辨率、片源、编码、HDR、音轨字幕等识别延续预览功能；名称识别不等于媒体流探测。
- 电视剧支持按季独立收藏、单季/多季导入、部分失败重试和手动补录。系列筛选与组内自然排序保留；下拉菜单使用深色主题。
- 背景使用高清横版图库，无字优先，不再直接取首张单集剧照；海报优先明确简体/大陆标记，其次英文，通用zh不作为简体依据。图像文字未做OCR，图库地区/语言标记准确性仍受来源影响。

升级保持应用身份、数据目录和凭据格式。数据库schema v4不新增迁移；从1.1.0的v2升级时自动保存迁移前快照，旧版不能直接打开v4数据库，回退前须保留新库并使用升级前快照。安装器支持取消桌面快捷方式并记住选择，窗口无原生编辑/视图菜单。

下载 `My-Cinema-1.2.0-Setup.exe` 或 `My-Cinema-1.2.0-portable-win64.zip`，校验值见 `SHA256SUMS.txt`。更新后，可在影视库点「全部刷新」统一更新已有资料与图片。

自动化验证使用隔离收藏及受控夸克/TMDB接口，并独立检查真实Windows窗口、安装器和加密凭据兼容。真实个人账号/Key完整链路、个人电脑升级与缩放仍需单独验收，不以正式版本号代替这些验证。Windows不包含播放/下载；电视端保持独立0.1.0-alpha.3预览，WebDAV与电视播放仍在后续计划。
