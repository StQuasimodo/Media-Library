# 审计后第一批修复

本批保留 Electron / React / SQLite 架构，不改数据库结构或产品功能边界。

## 行为变化

- 开发模式首次构建和监听构建统一写入 `dist-electron/main.cjs`、`preload.cjs`。重启前等待旧进程退出，退出开发模式时清理 Electron，避免加载旧代码或遗留实例。
- 首页想看列表从整个收藏库独立选取最近6部，真实总数不变；较早收藏的想看作品不再被最近12部列表排除。
- 背景实际加载并解码成功后才进入淡入；切换取消过期加载结果及清理定时器。背景失败时依次尝试海报、空背景；减少动效时直接替换。
- 焦点轨道、影视库卡片与详情页共用海报失败回退。缓存路径非空但文件不可用时显示标题/年份，路径更新后重新尝试加载。

- 首页保留唯一的焦点轨道，删除重复的最近收藏卡片区。收藏总数和全部收藏入口位于轨道之后；夸克资源入口降为次级文字操作。

## 第三批：可靠性与夸克目录入口

- 同一秒的备份与导出使用独立文件名，避免覆盖旧快照。
- SQLite一致性快照失败时明确失败，不退回可能遗漏WAL内容的原始数据库文件复制。
- 凭据文件写入成功后才更新内存缓存，避免“保存失败但本次会话看似已更新”。
- 修正之前没有真正删图的持久化测试，现在实际删除缓存文件并重开数据库验收。
- 设置页目录导航使用HashRouter内的链接，修复锚点被误当路由；页面重置滚动在布局阶段执行，保留之后的目标锚点定位。
- 新增夸克只读文件夹设置与读取服务，详见 [官方方案与实现边界](QUARK-FOLDERS.md)。这是自动读取清单与识别线索阶段，真实账号、TMDB自动入库与作品关联未完成。

第三批最终验证：8个测试文件、82个测试全部通过；完整构建（含类型检查）通过；真实Electron桌面检查通过。结果在 `.harness/desktop-smoke-UFPmeg/report.json`，夸克设置截图在同目录 `09-quark-folder.png`。夸克的目录数据来自测试CLI，报告明确标注fixture，不是用户真实账号。未安装官方Skill、未发起OAuth、未读取真实网盘；用户已说明尚未配置授权。
