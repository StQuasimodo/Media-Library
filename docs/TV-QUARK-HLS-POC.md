# TV：夸克云端 HLS 手动试播 PoC

## 范围与入口

TV 开发预览 `0.3.0-alpha.7`（versionCode 15）。媒体源进入已挂载夸克目录，选择文件 → **检查云端播放版本** → 选就绪的 HLS → **试播此HLS版本**。原文件播放入口保持独立；不自动降级或替换原文件。服务端给出版本地址不代表已验证实际编码、解码路径或电视能力。

本阶段将前一阶段的只读检查接成严格受限的完整点播 HLS 试播。此实现不是电视本地转码，不会改善电视芯片能力；依赖夸克账号实际提供可访问的云端版本。`fmp4_av` 独立响应、直播、低延迟 HLS、DRM、多域名分片/重定向尚不支持。HLS 内含 fMP4 初始化段与分片的情形单独验证。

## 结构与约束

- `MediaSources.cloudHls`：验证当前挂载目录权限后重新查询 `file/v2/play/project`。用档位、尺寸、编码等稳定标识重新选择，地址仅存在于内存，不将 Cookie 交给 LibVLC。
- `CloudHlsSession`：保存单个静态播放清单图谱，重写主清单、子清单、音频清单、MAP、KEY、分片地址到不含上游路径和签名的不透明本机路由。全部上游引用必须是同源 HTTPS；跨域重定向拒绝。
- `CloudHlsRelay`：仅监听 `127.0.0.1`，每次试播独立端口、随机路径与 Basic 凭据，只允许 GET/HEAD。解码器得到的仅是这个临时端点及本机凭据。上游只获取其需要的 Cookie/Referer/UA，本机 Authorization 不上送。
- `MediaTransfer`：沿用现有 Range、最多 4 MiB 顺序请求、64 KiB 拷贝、字节范围与长度校验、有限断流恢复。增加仅云端使用的同源重定向限制与媒体类型/首部嗅探，拒绝伪装为分片的 M3U8 或错误网页。不写电影文件或磁盘分片缓存。
- 地址到期、401/403：重新获取根版本、沿父子路径更新分片地址。原始时间轴与资源身份摘要须保持一致，否则失败并要求重连，避免拼接不同影片/时间轴。仅明确的签名/有效期字段不计入身份；未知变化不会静默忽略。
- 限制：单清单 256 KiB/2000 引用、图谱 4096 节点/4 层、已重写清单 LRU 8 项、每项 512 KiB；3 个工作线程、4 个排队请求。仅缓存有界元数据，媒体按需转发。
- 停止、重连、旧连接淘汰：取消网络作用域、关闭套接字并销毁图谱；不停止原文件的 Quark DAV 挂载。
- `CloudPlaybackProgress`：单独保存媒体标识 + 稳定版本标识的哈希及时间，不保存地址/凭据，不覆盖 `MediaCatalog` 原文件进度。**实验性云端试播进度暂不纳入现有备份**；卸载/清数据会丢失。重新登录、断开连接不主动删除进度。原收藏、关联、凭据和原文件进度的备份格式不变。

## 验证办法

自动化使用临时 HTTPS 受控服务返回合成 180 秒 1080p H.264/AAC fMP4 HLS，不使用真实夸克凭据或电影。临时 CA 与 hosts 只安装到可销毁 API22 模拟器；应用 TLS 验证保持开启，夹具与测试 APK不打入产品。

- 宿主机：25 项 HLS 清单策略、26 项云端版本选择/状态策略；现有 234 项业务测试。
- 全部 Java 主源码与 instrumentation 编译；实际 Gradle lint/APK 构建、API21 安装门槛、v1 签名及 ARMv7/x86 库检查由 Android workflow 执行。
- API22：真实本机端点的认证、子清单/MAP 重写、Range/HEAD、403 后一次根地址刷新、字节相同与稳定本机路由；清单时间轴变化、伪装分片的清单、跨域重定向拒绝。
- API22 LibVLC：实际解码音视频并显示帧、定位约 40 秒、遥控器暂停、暂停时重连、恢复播放、退出后重新打开续播；原文件进度/身份不变；关闭试播后原 DAV 仍可读。

最终执行结果、源码提交、CI 地址与 APK 哈希在验收完成后记录。当前代码和测试定义不等同于已验收。

## 尚未验收

真实夸克账号/会员版本覆盖率、真实 CDN 的签名规则和域名分布、ARMv7 实际运行、长虹55D2S 实机、4K HEVC/HDR/高码率原盘、加密 HLS 实际解码、多音轨/字幕与云端原片的一致性。解析器能重写 AES-128 KEY、音频清单，不代表已经证明对应解码播放成功。硬解/软解仍须以原生实际观测为准。
