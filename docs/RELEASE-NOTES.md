私人 Windows 影视收藏应用，支持电影与剧集、个人评分和短评、自定义专题，以及 SQLite 本地备份与恢复。

- 沉浸式首页、横向焦点海报轨道、背景联动，以及统一的电影详情与专题页面。
- TMDB 搜索导入和图片缓存；需要在设置中配置自己的 API Key。
- 夸克分享资源记录与指定云端文件夹只读清单。目前没有应用内关联夸克账号的授权入口，目录读取需要独立安装并授权夸克官方工具；自动匹配入库与作品关联尚未完成。

安装：下载 `My-Cinema-1.0.0-Setup.exe`。也可下载免安装 ZIP，解压后运行 `My Cinema.exe`。可选的 `INSTALL.cmd` / `RUN-PORTABLE.cmd` 须与对应下载文件放在同一可写目录。

支持 Windows 10 / 11 x64。安装包未做代码签名，Windows 可能显示 SmartScreen 提示；下载后可对照 `SHA256SUMS.txt` 检查文件哈希。本应用不提供播放或下载功能。

Windows CI 测试与桌面检查不代替个人电脑上的安装、系统缩放及真实账号验收；TMDB 在线完整链路与夸克真实账号读取仍待验证。已有收藏保存在用户数据目录，升级前建议在设置中备份。
